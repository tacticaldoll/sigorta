# sigorta

Curated entrypoint for [Sigorta](https://github.com/tacticaldoll/sigorta): a thin,
sans-I/O circuit-breaking core you compose. This crate is a pure re-export of
`sigorta-contract`'s public surface — see that crate's README, or the workspace root
`PROJECT.md`, for the full contract.
